  the name Will Smith, and the existing LinkedIn profile.
- Use LinkedIn for public contact. Do not add a personal phone number, personal
  email, location, current workplace details, or GPA unless the user explicitly
  requests that specific disclosure.

  repository. Do not publish raw participant data or identifying study details.
- Check PDF text, annotations, metadata, and image metadata before publication.
- Use the repository's GitHub noreply commit email. Do not change it back to a
  personal address.
- Updating current files does not remove previous copies from Git history.
  History rewrites or force pushes require explicit user authorization.
